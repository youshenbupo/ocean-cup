# ️ 工友权益明白人

> 为人民建好房 · 为工友谋幸福

专门服务建筑工友（尤其是农民工）的权益保障法律顾问和贴心伙伴。

##  项目简介

建筑工友群体文化程度普遍不高、维权意识薄弱、对法律条文感到陌生。本智能体将法律"翻译"成工友听得懂、用得上的大白话，给出明确可执行的下一步动作，解决工友"不知道自己有什么权益、不知道怎么维权、不知道找谁能帮忙"的三大痛点。

**参赛赛事**：第一届"海之子"杯 AI 智能体挑战计划（中国建筑国际集团主办）

## ✨ 核心功能

### 七大专业Agent

| Agent | 功能 | 触发场景 |
|-------|------|----------|
| ⚖️ 法律顾问 | 权益问答、维权指引、证据清单 | 欠薪、工伤、合同、辞退 |
| 🦺 安全守护 | 安全隐患识别、安全报告 | 工地照片、安全问题 |
| 💬 心理陪伴 | 情绪疏导、危机干预 | 烦躁、疲惫、想家 |
|  薪资管家 | 工时记录、工资核算、欠条 | 记工、算工资、欠薪 |
| 🎓 技能导师 | 技能提升、考证指导 | 学技术、考证、培训 |
| 🏠 生活管家 | 社保医保、子女教育 | 报销、上学、租房 |
| 👥 工友社区 | 互助问答、经验分享 | 发帖、求助、分享 |

### 回复格式

**简单咨询**：
```
【你的问题】{复述问题}
{大白话解答}
📌 法律依据：《XX法》第X条
💡 一句话总结：{行动建议}
```

**维权指引**：
```
【你的情况】{复述并归类}
⚖️ 法律怎么说
🪜 你该怎么办（分步骤）
📁 要准备的证据（必备/辅助）
🆘 找谁能帮忙
```

## 🛠️ 技术架构

### 多Agent协作
```
用户输入 → Router Agent → 专业Agent → 输出
                    ↓
              7个专业Agent
              (legal/safety/support/salary/skill/life/community)
```

### 知识库
- **32个权威文档**
  - 7部法律法规全文
  - 3篇政策解读
  - 3篇典型案例
  - 2篇维权渠道
  - 17篇专业指南

### 工具集
- 知识库检索（混合检索+重排序）
- 天气安全提醒
- 工时记录与工资核算
- 社区帖子管理
- 安全隐患识别（多模态）
