## 项目简介

"工友权益明白人"是专门为建筑工友（尤其是农民工）服务的权益保障法律顾问智能体。我们扎根建筑工地，熟悉《劳动法》《劳动合同法》《保障农民工工资支付条例》《工伤保险条例》等法律法规，用最接地气的语言帮工友搞明白自己的权益、理清维权的路子。

### 核心痛点

建筑工友群体文化程度普遍不高、维权意识薄弱、对法律条文感到陌生。本智能体解决工友三大痛点：
1. **不知道自己有什么权益**
2. **不知道怎么维权**
3. **不知道找谁能帮忙**

### 能力等级

**L6+ 级别** - 基于AI重新设计业务流程，实现多Agent协作、知识库检索、工具调用、数据库持久化等完整功能。

**重要**: 本项目包含WebSDK的配置信息，但**不包含token**。

### WebSDK相关文件

1. **项目ID**: `7668109916292284459`
   - 位置：`config/agent_llm_config.json`
   - 位置：`frontend/index.html`
   - 位置：`frontend/TASK.md`

2. **WebSDK链接**: `https://code.coze.cn/web-sdk/7668109916292284459`
   - 这是扣子平台生成的公网可访问链接
   - 任何人打开即可使用

3. **Token**: ⚠️ **不包含在项目中**
   - Token需要在扣子编程平台获取
   - 路径：部署 → 查看接入方式 → Web SDK → 复制token
   - Token格式：类似 `pt-xxx` 的字符串

### 如何获取完整WebSDK数据

1. 登录扣子编程平台
2. 打开"权益明白人智能体"项目
3. 点击「部署」→「查看接入方式」
4. 选择「Web SDK」标签
5. 复制以下信息：
   - 项目ID
   - CDN地址
   - Token
   - 完整初始化代码
