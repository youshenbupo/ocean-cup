【政策解读】欠薪治理政策要点

一、国家欠薪治理的"四项基本制度"

《保障农民工工资支付条例》建立了四项核心制度，从源头保障农民工工资支付：

1. **农民工工资专用账户制度**
   - 施工总承包单位必须开设"农民工工资专用账户"
   - 建设单位拨付的人工费用必须进入该专户
   - 工资直接从专户发到工人银行卡，不经过包工头手
   - ⚠️ 如果你的工资不是从"工资专户"发的，可能违规

2. **实名制管理制度**
   - 所有建筑工人必须实行实名制管理
   - 进场前要签合同、做登记、办考勤
   - 没有实名制记录，维权时举证困难

3. **工资保证金制度**
   - 施工总承包单位必须存储工资保证金
   - 一旦发生欠薪，保证金优先用于支付工人工资
   - 保证金金额一般为工程造价的1%-3%

4. **总包代发制度**
   - 分包单位招用的工人，由施工总承包单位通过工资专户直接发工资
   - 杜绝"层层转包、层层克扣"

二、建设单位（甲方）的责任

1. **资金到位才能开工** — 没钱的项目不能开工
2. **提供工程款支付担保** — 保证有钱付工程款
3. **按月拨付人工费用** — 人工费和材料费分开拨付
4. **不得要求施工单位垫资建设** — 特别是政府项目

三、施工单位（总包/分包）的责任

1. **与工人签订书面劳动合同**
2. **进行用工实名登记**
3. **建立劳动用工管理台账**（考勤、工资表等）
4. **编制工资支付表并经工人签字确认**
5. **通过工资专户按月足额发放工资**

四、遇到欠薪怎么办？—— 三步维权法

```
第1步：协商（最快）
↓ 和老板谈，最好录音留证据
协商不成 →

第2步：投诉（7-15天有结果）
↓ 打12333或去当地劳动监察大队
投诉还不行 →

第3步：仲裁（45-60日出裁决）
↓ 向劳动争议仲裁委员会申请
对裁决不服 →

第4步：诉讼（向法院起诉）
```

六、法律依据速查

- 《保障农民工工资支付条例》第30条：分包单位拖欠工资的，总包先行清偿
- 《保障农民工工资支付条例》第31条：工程转包导致欠薪的，总包先行清偿
- 《劳动合同法》第30条：用人单位应按时足额支付劳动报酬
- 《劳动合同法》第85条：逾期不支付的，加付50%-100%赔偿金
- 《刑法》第276条之一：恶意欠薪可构成犯罪（拒不支付劳动报酬罪）

七、恶意欠薪入刑标准

根据《刑法》第276条之一和相关司法解释：
- 以转移财产、逃匿等方法逃避支付劳动报酬
- 数额较大（5000元-2万元以上，各地标准不同）
- 经政府有关部门责令支付仍不支付
- 最高可判处3年以下有期徒刑，并处或者单处罚金

八、给工友的建议

1. **进场就签合同** — 不签合同是维权的最大障碍
2. **每天打卡考勤** — 考勤记录是最重要的证据之一
3. **工资走银行卡** — 现金发工资没有记录，很难证明
4. **保留微信聊天记录** — 与老板关于工资的对话截图保存好
5. **欠薪第一时间行动** — 别等工程结束再要，越早越好
6. **别签任何"放弃追索"的文书** — 有些老板会让签"结清证明"，千万别乱签
