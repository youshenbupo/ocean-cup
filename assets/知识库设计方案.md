## 三、知识库文档格式规范

上传至扣子知识库的文档需统一格式，确保检索效果：

### 3.1 法律法规文档格式

```
【法律法规】《中华人民共和国劳动法》

颁布机关：全国人民代表大会常务委员会
施行日期：1995年1月1日
最近修订：2018年12月29日

第一章 总则

第一条 为了保护劳动者的合法权益，调整劳动关系，建立和维护适应社会主义市场经济的劳动制度，促进经济发展和社会进步，根据宪法，制定本法。

第二条 在中华人民共和国境内的企业、个体经济组织（以下统称用人单位）和与之形成劳动关系的劳动者，适用本法。

...
```

### 3.2 案例文档格式

```
【案例】张某诉某建筑公司追索劳动报酬案

案情简介：
张某于2023年3月至2023年11月在某建筑公司承建的工地从事钢筋工工作，双方未签订书面劳动合同。工程完工后，公司尚欠张某工资28000元，张某多次催要未果。

争议焦点：
1. 未签订劳动合同是否影响劳动关系的认定？
2. 张某能否直接追索劳动报酬？

裁判结果：
法院经审理认为，虽未签订书面劳动合同，但根据张某提供的工牌、考勤记录、工友证言等证据，可以认定双方存在事实劳动关系。判决建筑公司支付张某工资28000元及经济补偿金。

法律依据：
《劳动合同法》第七条：用人单位自用工之日起即与劳动者建立劳动关系。
《劳动合同法》第八十二条：用人单位自用工之日起超过一个月不满一年未与劳动者订立书面劳动合同的，应当向劳动者每月支付二倍的工资。

维权启示：
1. 未签合同不等于没有劳动关系，工牌、考勤、工资记录、工友证言均可作为证据；
2. 遇到欠薪应尽早收集并固定证据；
3. 可通过劳动监察投诉或劳动仲裁维权。
```

## 四、扣子知识库上传操作步骤

1. 登录扣子平台（coze.cn），进入 Bot 编辑页；
2. 左侧导航选择"知识库" → "创建知识库"；
3. 命名为"工友权益法律知识库"；
4. 选择"文本"类型，上传上述 15 份 txt 文档；
5. 分段策略选择"自动分段"，或手动设置：
   - 分段长度：500-800 字
   - 分段重叠：50 字
6. 向量化完成后，在 Bot 配置中关联该知识库；
7. 测试检索效果，调整分段参数。

## 五、知识库维护建议

- 法律法规更新时（如新司法解释发布），及时替换对应文档；
- 案例库每季度补充 2-3 个新案例；
- 维权渠道信息每年核对一次（电话号码、地址可能变更）；
- 在知识库说明文档中记录最后更新日期。
