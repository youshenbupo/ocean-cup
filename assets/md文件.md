# Ocean Son Cup Agent 网页完整测试与优化方案报告

## 一、项目概述

项目名称：

Ocean Son Cup Agent

产品定位：

面向工友群体的劳动权益 AI 助手，帮助用户解决：

-   工资拖欠
-   工伤咨询
-   劳动合同问题
-   社保问题
-   劳动仲裁
-   投诉材料生成
-   法律知识查询

本报告从真实用户使用角度，对网页 Agent 产品进行完整测试，并提出
UI、交互、架构、功能、Agent 能力和后续迭代建议。

------------------------------------------------------------------------

# 二、测试目标

本次测试目标：

1.  验证普通用户是否能够快速找到解决问题入口。
2.  验证首页功能是否符合 Agent 产品逻辑。
3.  验证知识库、工具、聊天系统之间是否形成闭环。
4.  检查移动端和 PC 端显示效果。
5.  检查用户操作流程是否顺畅。
6.  提出可以直接实施的修改方案。

------------------------------------------------------------------------

# 三、用户模拟测试场景

## 用户角色

模拟用户：

-   建筑工人
-   年龄 40-55 岁
-   使用手机访问
-   对互联网产品不熟悉
-   主要需求是快速解决劳动问题

    打开网页

    ↓

    查看首页

    ↓

    寻找帮助入口

    ↓

    选择问题类型

    ↓

    进入 AI 咨询

    ↓

    提交问题

    ↓

    查看解决方案

    ↓

    保存结果

测试重点：

用户是否可以在 10 秒内知道：

"我要在哪里咨询？"

# 四、首页测试结果

# 问题1：首页定位不够明确

## 测试过程

用户打开首页。

看到：

-   多个功能模块
-   多个入口
-   多个工具

用户无法立即判断：

"我是应该点击法律维权，还是直接输入问题？"

------------------------------------------------------------------------

## 当前问题影响

普通用户不是来浏览产品功能，而是带着问题寻找解决方案。

当前页面容易产生：

-   选择困难
-   页面停留时间增加
-   用户流失

------------------------------------------------------------------------

## 修改方案

首页重新设计。

调整为：

    顶部：

    AI劳动权益助手

    请输入您的问题


    中间：

    常见问题


    底部：

    工具和知识库

------------------------------------------------------------------------

## 修改实现方式

新增核心组件：

ChatEntry

功能：

-   输入框
-   快捷问题
-   场景选择

例如：

用户点击：

"工资拖欠"

自动执行：

    createConversation(
     scene="salary"
    )

进入：

    /chat?id=xxx

# 五、功能入口测试

## 测试内容

测试：

-   工资问题
-   工伤问题
-   法律维权
-   知识库

------------------------------------------------------------------------

## 发现问题

目前功能入口更像普通网页导航。

没有形成：

入口 → AI → 解决方案

流程。

------------------------------------------------------------------------

# 修改方案

所有入口统一进入聊天系统。

例如：

工资入口：

    salary

工伤入口：

    injury

合同入口：

    contract

进入聊天后：

自动加载：

系统提示词：

    你是工资维权助手。

    需要帮助用户收集：

    地区

    欠薪金额

    劳动关系

    证据情况

## 测试流程

《工伤认定流程》

增加：

    根据我的情况分析

    chat context:

    正在阅读：
    工伤认定流程

    请结合我的情况分析。

第一优先级：

1.  首页改造成 AI 服务入口。
2.  所有功能统一进入聊天。
3.  增加多会话管理。
4.  打通知识库和聊天。
5.  完成移动端适配。

第二优先级：

1.  案件管理。
2.  证据管理。
3.  智能追问。
4.  自动生成材料。

最终目标：

从：

    AI聊天网页

    劳动权益智能办事助手
