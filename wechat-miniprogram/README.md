# 工友权益明白人 - 微信小程序

## 项目简介

「工友权益明白人」微信小程序，为建筑工友提供一站式权益保障服务。

## 功能模块

### 1. 首页
- 快捷功能入口（法律咨询、安全守护、薪资管家、技能提升、生活助手）
- 紧急求助按钮
- 热门问题推荐

### 2. 智能对话
- 多Agent智能路由（法律顾问、安全卫士、心理伙伴、薪资管家、技能导师、生活管家）
- 语音输入支持
- 图片上传（工伤取证、安全隐患识别）
- 对话历史记录

### 3. 工友社区
- 发帖求助
- 浏览帖子（按标签分类：欠薪、工伤、合同、社保、技能、生活）
- 点赞、评论互动
- 经验分享

### 4. 个人中心
- 工时记录
- 工资核算
- 我的帖子
- 收藏内容
- 设置

## 开发说明

### 环境要求
- 微信开发者工具
- Node.js 14+

### 配置步骤

1. **修改API地址**
   
   在 `app.js` 中修改 `apiBaseUrl` 为你的后端服务地址：
   ```javascript
   globalData: {
     apiBaseUrl: 'https://your-api-domain.com'
   }
   ```

2. **后端API接口**
   
   小程序需要以下后端接口：
   - `POST /api/chat` - 智能对话
   - `GET /api/community/posts` - 获取帖子列表
   - `POST /api/community/posts` - 发布帖子
   - `POST /api/community/posts/:id/like` - 点赞
   - `POST /api/community/posts/:id/comment` - 评论
   - `GET /api/work-records` - 获取工时记录
   - `POST /api/work-records` - 添加工时记录

3. **图片上传**
   
   工伤取证和安全隐患识别需要图片上传接口：
   - `POST /api/upload` - 上传图片
   - `POST /api/safety/analyze` - 分析安全隐患

## 部署步骤

1. 在微信公众平台注册小程序
2. 获取 AppID
3. 在微信开发者工具中导入项目
4. 配置服务器域名（需HTTPS）
5. 提交审核并发布

## 注意事项

1. 小程序需要备案域名才能使用
2. 图片上传需要配置合法的上传域名
3. 涉及用户隐私数据需要做好加密
4. 建议接入微信登录，方便工友使用
